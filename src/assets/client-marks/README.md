# 客户端标志

Claude / OpenAI 标志来源于 cc-switch 的 `src/icons/extracted`，本地参考提交 `1ee2fdc`。OpenCode 标志依据同目录 `opencode-logo-light.svg` 转成随主题前景色显示的轮廓。Pi 标志在 `configuration-shortcuts.tsx`，来自 Pi 官方 README 的几何标志（cc-switch 同路径的索引提供相同路径）。品牌标志仅用于识别对应客户端。

参考：[cc-switch](https://github.com/farion1231/cc-switch)、[Pi](https://github.com/earendil-works/pi)。
