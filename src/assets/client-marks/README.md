# 客户端标志

Claude / OpenAI 标志来源于 cc-switch 的 `src/icons/extracted`，本地参考提交 `1ee2fdc`。OpenCode 标志是 opencode.ai 官方 favicon（`https://opencode.ai/favicon.svg`，去掉了主题样式块）。Pi 标志在 `configuration-shortcuts.tsx`，取自 pi.dev 官方 favicon（`https://pi.dev/favicon.svg`）的三段几何路径，颜色随主题前景色。品牌标志仅用于识别对应客户端。

参考：[cc-switch](https://github.com/farion1231/cc-switch)、[OpenCode](https://opencode.ai)、[Pi](https://pi.dev)。
