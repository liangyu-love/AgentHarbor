# 余额自动查询

在中转卡片的「查询余额」窗口中，设置「自动查询间隔（分钟，0 表示不自动查询）」并保存。支持 0–10080 的整数分钟；已有配置默认 0。保存间隔不会立即发起余额查询，手动刷新仍可使用。

共享余额的同站点卡片使用同一份间隔，只查询余额所属卡片一次。切换为独立余额时保留当前间隔，之后可以分别设置。

应用运行期间按设定间隔查询，切换页面或最小化后继续工作，退出应用后停止。调度每 15 秒检查一次，并顺序处理到期站点；网络请求耗时可能使实际刷新略晚于设定时间。查询失败保留上次余额，下一轮按设定间隔重试。

成功查询会更新中转卡片，以及「账号和用量 → 中转用量 → 供应商与额度」中的余额。余额查询与路由 token/费用统计各自独立，路由用量记录不会自动推算账户余额。
