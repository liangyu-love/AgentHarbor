# Claude Code 本地会话

线程页按 Codex / Claude Code 切换来源，两个来源的列表、详情缓存和选中状态分别管理。原有 Markdown / JSONL 是导出格式，仍可在导出操作附近选择。

Claude Code 会话读取配置目录下的 `projects/<项目目录>/<会话 UUID>.jsonl`。配置目录与现有 Claude Code 接入共用路径解析：优先使用隔离的 `AGENT_HARBOR_CLIENT_HOME`，其次使用 `CLAUDE_CONFIG_DIR`，最后为用户目录下的 `.claude`。Claude Desktop 的聊天存储不属于这个来源。

会话支持查看消息、推理、工具调用及结果、压缩记录和日志中的用量，导出 Markdown / 原始 JSONL，以及复制 `claude --resume <UUID>`。本模块只读原始日志，不删除会话或改写其恢复数据；Codex 原有删除和恢复功能继续使用原来的路径。

工具结果归类为工具消息，不计为用户提问。同一 assistant message ID 的流式记录只计一次最终用量；输入统计包含日志中报告的缓存读取和创建 token。缺失的 provider 不根据模型或协议猜测，未报告的缓存用量保持未知。

只扫描项目目录直接包含的 UUID 日志，跳过子 agent、journal 和目录链接。损坏日志单独告警，正常日志仍能展示；有效日志中的非法行也会报告。列表缓存最多保留 4096 个摘要，单次发现最多 10000 个会话，单文件最多 512 MiB、单行最多 8 MiB。消息每页 50 条，单条展示最多 20000 字符。

详情生成日志前缀的 SHA-256 快照。Claude Code 后续追加日志不会改变已打开详情的分页，截断或替换旧内容会要求刷新，避免把两个版本的消息混在一起。导出使用独立临时文件及不覆盖发布，失败会清理本次新建文件，不修改原始日志和既有导出。

相关测试在 `src-tauri/src/core/claude_sessions/tests.rs`，覆盖来源筛选、异常文件、标题、用量去重、缓存告警、消息角色、分页快照、路径隔离和导出失败清理。测试只使用临时目录。

2026-10-07 验证：Windows MSVC 整库 Rust 回归（1014 lib、14 Desktop 工作流、20 本地工作流）、完整 `pnpm test:frontend` 和 `pnpm build` 通过。浏览器回归验证双来源缓存隔离、迟到响应、切换清空旧选择、键盘焦点、继续命令及两种导出格式，并核对桌面浅色和移动端深色截图。没有改写真实会话日志。
