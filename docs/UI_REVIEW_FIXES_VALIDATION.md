# UI 审查问题修复（2026-09-30）

范围：修复 `cfc34ff`、`04382d3` 中已复现的三个前端问题，不修改认证、Router、真实会话或 Rust 后端。

## 修复

1. **线程网格重叠**：移除网格项目组的绝对定位和累计高度窗口计算，改为正常文档流；卡片换行后由浏览器计算实际高度。保留 `content-visibility: auto`，使用记忆实际高度的 `auto` intrinsic placeholder。紧凑列表仍按固定行高虚拟化。虚拟/普通网格共用一份 250px 最小列宽、12px 间距；估算只影响离屏占位，不再决定项目的位置。网格模式不再注册无用的滚动状态更新。
2. **壁纸模式背景透明**：重置卡弹层恢复 `bg-popover`，线程详情恢复 `bg-background`；沿用壁纸变量自带的透明度，避免叠加 `/95` 或 `/90` 生成无效 HSL。不改写全局颜色变量，不取消用户壁纸。
3. **消息筛选状态串位**：筛选保留原始页内位置，组件 key 由快照字节数、分页偏移和原始位置组成；相同时间戳、相同角色的不同消息不会共享状态，留在结果中的消息保留自己的状态，新分页/快照不能继承旧状态。
