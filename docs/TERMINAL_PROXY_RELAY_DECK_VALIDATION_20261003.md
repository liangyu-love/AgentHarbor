# 终端代理与同 URL 卡片堆叠：审查与验证

日期：2026-10-03。基于当前磁盘工作区实现，保留既有未提交修改。

## 功能与边界

- 终端代理：设置页独立编辑当前 Windows 用户的 HTTP/HTTPS 代理；保存四个代理环境变量，保留本机直连；关闭时恢复原始注册表类型与字节；外部修改保留，部分失败可恢复。新终端应用继承配置，“打开 PowerShell”立即使用已保存值。不修改当前应用进程环境，不改变应用 API 代理配置。
- 同 URL 堆叠：复用现有 URL 归组，每层 7px/1.7°，最多五层；当前卡片移出后下一张展开。空白点击、左右按钮、键盘均可翻页；保留独立配置、余额、开关与操作身份。只有一张交互卡面，不自动轮播。减少动画时直接切换。
- 后端平台操作、所有权日志、设置 UI、归组/选择状态和动画时序分别封装。未新增卡片分组数据，也未合并供应商凭据。

## 审查发现与修复

1. 终端恢复中途失败后未广播已完成的环境变更。现成功、部分失败都广播，失败保留恢复日志。
2. 日志读取上限小于允许保存的原始环境变量总量。上限调整为覆盖全部合法字段，补较大原值精确恢复回归。
3. 堆叠空白点击被祖先 role 阻断，portal 事件可能误触发翻页。限制交互排除范围，核对目标属于当前堆叠。
4. 同批重复点击与过期目的成员。pending ref 锁定当前翻页，layout cleanup 在目的成员删除、展开、过滤卸载或选择改变时取消定时器。
5. 原生 disabled 翻页按钮可能丢失键盘焦点。使用 aria-disabled 和输入保护，补 group 语义、快捷键与修饰键保护。
6. 堆叠留白缩小卡面，底栏按钮可能裁切。窄卡面隐藏余额按钮文字，保留图标、提示、可访问名称和全部操作。
7. 退出动画结束事件迟到后会清除新入口动画。只处理与当前入口 animationName 匹配的结束事件。
8. 极窄卡面标题被翻页区挤到零宽。300px 以下的多成员卡头分两行，补标题最小可读宽度回归。

审查后未发现剩余阻断问题。新终端代理未使用 shell 辅助程序，因此保存、恢复与读取不会新增 cmd 窗口。
