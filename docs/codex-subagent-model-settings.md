# Codex 子代理默认配置

入口：**中转注入 → Codex 接入 → 子代理默认配置**。

选择子代理模型与思考强度后点“保存”。Codex 接入关闭时只保存设置；
接入启用时同时应用配置。重启 Codex 后，新建子代理使用这份默认值。
主线程模型和已有子线程保持原样。

## 模型候选

候选复用当前接入目录，不另建模型表，也不改上游实际模型名。

| 接入模式 | 可选模型 ID | 实际出口 |
| --- | --- | --- |
| 普通路由 | 官方裸 ID，例如 `gpt-6-luna` | 官方账号 |
| 普通路由 | 中转命名空间，例如 `provider-id::gpt-6-luna` | 对应中转卡片 |
| Native | 当前选中中转的原始模型 ID | 当前中转直接连接 |
| 聚合 | 当前聚合目录中的公开模型 ID | 聚合调度后的成员 |

开启无账号登录模式后，普通路由仅提供中转模型候选。已固定为官方模型的
子代理设置需先改为中转模型或继承主模型，才可应用无账号模式。

思考强度来自该候选模型的既有能力配置。选择模型时会清除与新模型不兼容的
草稿档位。模型停用、删除或切换接入模式后，旧目标若不可用，会显示错误；
启用或应用时也会校验，不会偷偷换成官方模型。

## 继承与恢复

- 模型选“继承主模型”：删除受管的子代理默认模型键。
- 思考强度选“继承 / 模型默认”：删除受管的默认思考强度键。
  固定模型时由 Codex 使用该模型默认值；未固定模型时遵循其继承规则。
- “恢复原配置”：撤销本功能对两项设置的接管，还原首次接管前的值。
- 关闭 Codex 接入：还原原配置；已保存的选择保留，下次启用再应用。

普通重新应用不会移动恢复点。恢复仅处理仍等于本工具最后写入值的字段，
保留用户或其它工具后来改动的值。`agents` 中的并发限制、自定义角色、
其它设置和主线程配置不由本功能接管。

## 官方契约

写入的是官方配置字段：

```toml
[agents]
default_subagent_model = "provider-id::gpt-6-luna"
default_subagent_reasoning_effort = "xhigh"
```

显式 `spawn_agent` 模型/强度参数可以覆盖这些默认值；
自定义角色文件中的配置按 Codex 自身优先级继续生效。
本功能不重写旧子线程，不新增 Ultra 档位，也不启用服务端协作模式。

## 实现与验证

设置保存在既有中转配置存储中。应用、备份和原子写入复用
`CodexConfigRepository`；两项字段的恢复投影扩展既有配置 journal，
不新增第二条配置写入通道。旧 journal 缺少该投影时仍可读取；
未使用本功能的 journal 不写新增的空字段。

后端回归覆盖保存后启用、重复应用、继承、恢复、Native、聚合、
目标不可用、非法档位、外部接管、TOML 表/内联表，以及失败和中断写入。
前端覆盖保存与重开、恢复、不同模式候选、错误重试、操作锁、
长模型名、窄屏和深浅主题。

真实 Codex CLI 测试使用隔离 `CODEX_HOME`、合成 Free 认证与本地假上游。
测试驱动真实 `spawn_agent`，校验子代理出口模型、xhigh 和中转凭据，
主线程出口保持不变，修改默认值后恢复的旧子线程仍保留原模型。
所有推理请求留在回环地址；账号/服务发现的外网尝试由拒绝代理拦截，
不读取真实凭据、不消费额度。该用例验证本地子代理，关闭 `multi_agent_v2`。
